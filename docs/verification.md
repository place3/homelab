# Проверка работающего стенда

Состояние зафиксировано 22 октября 2026 года. Это проверка текущего состояния, а не нагрузочное тестирование или аудит безопасности. Команды выполнялись на сервере по SSH; сервисы не перезапускались и конфигурация не менялась.

## Контейнеры

```bash
docker compose ls
docker ps -a --format 'table {{.Names}}\t{{.Status}}\t{{.Ports}}'
```

На момент проверки 10 контейнеров находились в состоянии Up, в том числе Jellyfin, cAdvisor и Pi-hole с состоянием healthy. Дополнительно были два старых остановленных тестовых контейнера; их причина остановки не исследована.

## Prometheus

```bash
curl --fail --silent http://127.0.0.1:9090/api/v1/targets
```

Из ответа API были выделены следующие поля:

| job | health | lastError |
| --- | --- | --- |
| cadvisor | up | пусто |
| node_exporter | up | пусто |
| prometheus | up | пусто |

`up` подтверждает успешный сбор с этих целей на момент проверки. Настройки алертов, полнота метрик и retention отдельно не проверялись.

## Grafana

```bash
curl --fail --silent http://127.0.0.1:3030/api/health
```

API вернул состояние базы `ok`. Порт хоста 3030 опубликован на порт 3000 контейнера. Отдельная проверка содержимого дашбордов пока не выполнена.

## Система и firewall

```bash
systemctl --failed --no-pager
free -h
df -h /
sudo ufw status verbose
```

Неисправных units не обнаружено. Корневой раздел был заполнен на 39%. UFW включён, политики по умолчанию: deny incoming, allow outgoing, deny routed.

Полный доступ к опубликованным Docker-портам нельзя оценить только по UFW: требуется учитывать правила Docker и маршрутизатора. Доступ из интернета в ходе этой проверки не тестировался. Частные адреса, ключи, пароли и локальные рабочие данные в репозиторий не включены.
